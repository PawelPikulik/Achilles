## Generated Images: Style Spec

**Style name:** Dark Roast Precision

**Mood:** Warm, precise, minimal, technical but not cold. Deep espresso browns, dark slate grays, warm amber accents. No bright colors, no gradients that look like stock art.

**Rules for every generated image:**
- Dark background (charcoal or espresso), not white or light gray
- Thin, precise lines (technical, not organic)
- Minimalist composition, no clutter
- No text, no labels, no UI chrome — pure texture or abstract form
- Warm amber or copper accents only, no bright colors

**Hero texture prompt:**
> "Macro photography of dark roasted coffee beans, extreme close-up, shallow depth of field, warm amber light from the left, deep charcoal background, minimal, precise, no text, no labels, high contrast, 4K."

**Architecture diagram prompt:**
> "Minimalist technical diagram on dark charcoal background, thin precise copper lines connecting three abstract nodes, no text, no labels, clean geometric shapes, warm amber accent lighting, technical illustration style, 4K."

**Why these prompts are designed this way:**
- "Dark charcoal background" forces consistency with the hero
- "No text, no labels" prevents generated gibberish text that looks unprofessional
- "Thin precise copper lines" establishes the technical-but-warm aesthetic
- "No bright colors" keeps the palette restrained and premium

## Rejected Image: The Judgment Note

**What I generated:**
> Prompt: "A futuristic AI robot barista making pour-over coffee in a sleek modern café, holographic data streams floating around the cup, neon blue and purple lighting, hyper-realistic 8K."

**Why I rejected it:**

This image looked impressive for about 3 seconds. Then I asked: does this serve the Head of AI? Does it prove anything about the actual product? The answer is no.

Specific problems:
1. **The robot barista doesn't exist.** Achilles is a text-based AI agent, not a physical robot. The image creates a false impression of the product.
2. **Neon blue and purple lighting** is completely off-brand. The portfolio is warm, precise, grounded in real data. This looks like a sci-fi movie poster, not a portfolio for a Head of AI evaluating a backend integration.
3. **Holographic data streams** are decoration without substance. They suggest "AI magic" rather than "API integration, prompt engineering, and error handling."
4. **It would make the portfolio worse.** A Head of AI scrolling through would see this and think: "This person cares more about looking futuristic than about shipping real products." It undermines the claim.

**What I chose instead:** A real screenshot of Achilles answering a coffee question with the CoffeeDB.pro data citation visible. It looks less "cool." It proves more.

## Where Real Captures Beat AI

| Decision | Why Real Won |
|----------|--------------|
| Hero screenshot | Proves the product exists and works. A generated chat interface would be decoration. |
| Code snippets | Proves the integration is real. Generated "code-looking" text is detectable and would destroy credibility. |
| CoffeeDB API response | Proves the live data connection. A generated JSON blob would be meaningless. |
| Prompt ladder excerpt | Proves the iterative discipline. This is the core differentiator — it must be real. |
| Cross-model comparison | Proves honest evaluation. A generated table would be fabrication, which is the opposite of the claim. |
| Headshot | Proves the person is real. AI-generated headshots are increasingly detectable and signal "hiding something." |

**One principle:** If the image is evidence, it must be real. If the image is mood or illustration, it can be generated — but only if it serves the proof, not distracts from it.
