Featured Project

Achilles — AI Coffee Expert

A domain-specific AI product that answers coffee questions using structured bean data, remembers your taste preferences across sessions, and recommends beans that match both your query and your stated tastes.

  • Backend: FastAPI with Pydantic, rule-based matching engine, preference memory (regex + JSON persistence)
  • Frontend: Vanilla HTML/CSS/JS chat UI, CORS-enabled, identity-kit styling
  • Data: CoffeeDB-compatible schema, mock data with one-line swap path to live API
  • Testing: 10-query automated suite, all passing; 6 bugs documented and fixed in build log
